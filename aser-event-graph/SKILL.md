# ASER 研究工作流

本技能由 TITU Work 编写，帮助研究者使用香港科技大学 HKUST-KnowComp 的 [ASER](https://github.com/HKUST-KnowComp/ASER)。它是研究流程指南，不是原项目的代码、数据集或 MCP 服务。

## 准备

确定任务是浏览现有事件图谱，还是复现从文本抽取事件和话语关系。开始前核对原仓库 README、许可证和当前依赖；如果资料或数据不可获取，说明缺口，不虚构运行结果。

## 执行

阅读原仓库 README 与数据使用说明；检查公开数据下载链接和机器资源，先从可用的小样本读取事件及关系，再根据论文定义分析因果、时序或共现关系。仅在资源足够时运行抽取流水线。

## 交付

输出数据版本、事件/边的示例、关系类型、来源与噪声限制。说明哪些结果来自实际运行，哪些仅来自论文或仓库文档。

## 边界

大规模图谱需要较大磁盘和内存；原始文本与 Probase 派生数据需遵守各来源条款；不随本技能分发图谱。
